千址盒

一款面向个人用户的本地网址收藏、分类管理和应用内浏览工具。用户可以添加、编辑、分类、搜索和导入导出网址，并通过应用内浏览器打开主动输入或收藏的网址。

主要功能

本地网址收藏

支持保存用户主动添加的网址、标题、分类、标签和备注，方便个人整理常用网页入口。

分类与搜索

支持按分类、标签、标题、备注和网址进行搜索筛选，帮助快速定位目标收藏。

导入导出

支持通过 Markdown 或 JSON 文件导入导出收藏数据，便于用户自行备份和迁移。

应用内浏览

内置浏览器用于打开用户输入或收藏的网址，并提供搜索、复制、分享、收藏等辅助操作。

本地优先

应用不提供注册登录功能，收藏数据主要保存在用户设备本地，不主动上传到开发者服务器。

轻量实用

围绕网址管理这一核心场景设计，尽量保持功能清晰、使用简单、数据可控。
